# المرحلة 1 — الواجهة (apps/web)

> آخر تحديث: 2026-10-12. الواجهة كاملة للمرحلة 1، وتعمل بأحد محوّلين: الخادم الحقيقي (`HttpApi`) أو نسخة العرض داخل المتصفح (`DemoApi`) لـ GitHub Pages.

## ما بُني

**الأساس**
- React 18 + TypeScript (strict) + Vite + Mantine 7، و`<html dir="rtl" lang="ar">` مع `DirectionProvider`.
- الهوية البصرية من مهارة `nuzli-design-system` حرفيًّا: `src/theme/tokens.css` (فاتح وداكن)، وثيم Mantine مبنيّ عليها (اللون الأساسي «تيل الميدان» حول `#1D5C63`)، والخطوط مستضافة ذاتيًّا (IBM Plex Sans Arabic، Readex Pro، IBM Plex Mono).
- شريط السترة: الصنف `.vest` والمكوّنان `<VestBand>` و`<TeamBadge>` (اللون دائمًا مع اسم الفريق).
- النصوص كلها في `src/i18n/ar.ts` (٣٣٨ مفتاحًا)، و`en.ts` هيكل بالمفاتيح نفسها. `t()` مع التعويض، وتنسيق الأرقام (غربية افتراضًا، ومشرقية اختيارًا) والتواريخ (ميلادي افتراضًا، وهجري أم القرى اختيارًا، بتوقيت الرياض).
- `scripts/check-i18n.mjs`: يفشل إن نقص مفتاح في ar/en أو ظهر نصّ لاتيني في JSX.

**البيانات**
- `src/api/client.ts`: واجهة `ApiClient` لكل نقاط المرحلة 1 في `docs/API.md`. الشاشات لا تعرف أيّ محوّل يعمل (`useApi()`).
- `HttpApi`: رمز الوصول في الذاكرة فقط، وتجديد واحد مشترك عند 401 بترويسة `X-CSRF-Token` من `nz_csrf`، وأخطاء موحّدة `ApiError { code, message_ar }`.
- `DemoApi`: يعمل في المتصفح ويحفظ في IndexedDB (Dexie)، ويطبّق القواعد نفسها: مخطّطات zod المشتركة، و`can()`، ومنع دخول الحساب المعلّق، وحماية آخر مدير، وتفرّد البريد والجوال والهوية، وسجل التدقيق، وإشعار المديرين بكل طلب تسجيل.
- TanStack Query للبيانات، وZustand لحالة الدخول.

**الشاشات**

| المسار | المحتوى |
|---|---|
| `/login` | الدخول بالبريد أو الجوال؛ في نسخة العرض: كلمة المرور التجريبية وأزرار «دخول تجريبي» لكل صفة |
| `/register` | بطاقتا نوع الحساب (مشرف / مشرف مراقبة)، والحقول من `registerSchema`، واسم الفريق المقترح للمشرف، ومؤشّر قوة كلمة المرور |
| `/pending` | إشعار «طلبك بانتظار الاعتماد» |
| `/forgot-password` · `/reset-password?token=` · `/change-password` | الاستعادة والتعيين، والتغيير الإجباري عند `mustChangePassword` |
| `/` | للمدير: الطلبات المعلّقة، والحسابات النشطة حسب الصفة، والموقوفة، وآخر الإجراءات. للمشرف ومشرف المراقبة: ترحيب وما سيصل قريبًا |
| `/registrations` | الطلبات بتفاصيلها، والاعتماد مع تغيير الصفة قبله، والرفض بسبب إلزامي |
| `/users` | البحث والتصفية بالصفة والحالة، وإنشاء مستخدم (ومنهم المدير)، والترقية والخفض، والإيقاف وإعادة التفعيل، ورسالة `LAST_ADMIN` العربية من الخادم كما هي |
| `/audit` | التصفية بالإجراء والعنصر والمنفّذ والتاريخ، وعرض الحقول قبل وبعد |
| `/notifications` | الكل / غير المقروءة، وتعليمها مقروءة |
| `/profile` | الاسم، والأرقام، والتاريخ الهجري، والمظهر، وإشعارات البريد لكل نوع، وتغيير كلمة المرور |
| `/settings` | إعدادات النظام من `SETTINGS_SCHEMA` بعناوين عربية وحدودها من المخطّط |

- الإطار: شريط جانبي بلون `--ink` على اليمين بعرض 248px، يصير درجًا تحت 768px، وجرس إشعارات بعدّاد، وقائمة الحساب، وشريط «نسخة عرض» في نسخة العرض، وحلقة تركيز ظاهرة، واحترام تقليل الحركة، وفاتح وداكن.
- القائمة في سجلٍّ واحد `src/app/nav.ts`؛ عناصر المراحل اللاحقة تُضاف هناك فقط. المسارات محميّة بـ `can()`.
- رقم الهوية مقنّع في كل مكان، ويظهر كاملًا للمدير فقط في تفاصيل المستخدم أو بطلبٍ صريح في بطاقة الطلب.

## التشغيل

```bash
npm run build -w @nuzli/shared          # مرة واحدة، أو بعد تعديل الحزمة المشتركة
cd apps/web
npx vite                                 # تطوير مع الخادم الحقيقي (يمرّر /api إلى localhost:3000)
npx vite --mode demo                     # تطوير بنسخة العرض داخل المتصفح
npx vite build --mode demo && npx vite preview --mode demo --port 4173
# ثم افتح http://localhost:4173/nuzli-project-management/
```

الفحوص: `npx tsc --noEmit && npx vitest run && node scripts/check-i18n.mjs && npx vite build && npx vite build --mode demo`.

النشر: `.github/workflows/pages.yml` يبني نسخة العرض عند الدفع إلى `main` وينشرها على GitHub Pages (مع `404.html` للمسارات). و`ci.yml` يفحص الحزمة المشتركة والواجهة.

## الاختبارات (٢٦ اختبارًا ناجحًا)

- `DemoApi`: الحساب المعلّق لا يدخل، والاعتماد يتيح الدخول، وإشعار المديرين، وسجل التدقيق، والرفض يتطلّب سببًا، وحماية آخر مدير من الخفض والإيقاف، والإيقاف ينهي الجلسات، وتفرّد البريد والجوال والهوية، وفرض تغيير كلمة المرور، والصلاحيات، واستعادة الجلسة، والإعدادات، وإعادة الضبط.
- i18n: التعويض، والأرقام المشرقية، والتاريخ بتوقيت الرياض والهجري، وتطابق مفاتيح ar/en، ونجاح سكربت الفحص.
- الإطار: `dir="rtl"` و`lang="ar"`، والقائمة العربية للمدير، وإخفاء عناصر المدير عن مشرف المراقبة، وتحويل الزائر إلى صفحة الدخول.

## المتبقّي

- ربط الواجهة بالخادم الحقيقي واختبارها معه عند اكتمال `apps/api`، ومطابقة أسماء إجراءات التدقيق (ADR-028).
- اختبارات Playwright الشاملة (التسجيل ← الاعتماد ← الدخول) في `e2e/`.
- PWA ومزامنة المخالفات دون اتصال (المرحلة 3)، وشريط الجوال السفلي لمشرف المراقبة.
- ترجمة `en.ts` (هيكل الآن).
- التحقّق البصري الآلي جرى بلقطات Chrome بلا واجهة على 360×740 و1440×900 (فاتح وداكن)؛ لم تُختبر بعد على أجهزة حقيقية.
