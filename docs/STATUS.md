- **بيانات المالك الحقيقية** (الإدارات، والمسمّيات، وأنواع المخالفات، والشعارات، والإجازات): **بانتظار المالك**. النظام يعمل الآن ببيانات تجريبية موسومة في `seed/demo/`.

## عوائق تحتاج قرار المالك

1. **GitHub Actions:** رمز الدخول المحفوظ لا يملك صلاحية `workflow`، فيرفض GitHub رفع ملفات `.github/workflows/`. لذلك:
   - يُنشر العرض بدفع ملفات البناء إلى فرع `gh-pages`.
   - تُحفظ ملفات CI في `infra/github-workflows/` غير مفعّلة.
   - لتفعيل الاختبار والنشر التلقائيين: أنشئ رمزًا فيه نطاق `workflow`.
2. **Docker غير مثبّت** على هذا الجهاز، فلم يُشغَّل الخادم مع قاعدة البيانات فعليًّا، ولم تُشغَّل اختبارات التكامل. كل الملفات جاهزة لأي جهازٍ فيه Docker.
3. **GitHub Pages لا يشغّل خادمًا:** المنشور هناك نسخة عرضٍ ببياناتٍ تجريبية داخل المتصفح (ADR-020).
4. **طابعة Zebra:** معيار قبول المرحلة 2 يتطلّب طباعةً فعليةً بمقاسَي CR80 و٩٠×٤٠.
