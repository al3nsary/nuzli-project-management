## طُلب ولم يُنفَّذ بعد

- **A11 — حدود التصميم المعتمد:** فيغما شاشة واحدة (لوحة كانبان)، وباقي الشاشات تأخذ لغته ولا تطابق إطاراتٍ مستقلة؛ زرّ «Invite» وأيقونة التقويم لم يُضافا (لا ميزة مقابلة)؛ خط Inter مستبدل بـ IBM Plex Sans Arabic؛ ألوان نص الوسوم أغمق قليلًا للتباين. إن أرسل المالك إطارات لشاشات أخرى طابقناها.

- **المرحلة 5 (اختيارية):** خطوط الأساس، والمسار الحرج، وطباعة ZPL. (عبء العمل وقوالب المشاريع والمحافظ بُنيت في A9.)
- **خدمة PDF على الخادم** (كروت العمل ولوحة المخالفات): النقاط موجودة وتردّ برسالة واضحة حتى تُبنى الخدمة. في المتصفح يعمل PDF عبر نافذة الطباعة.
- **تحويل ‎.mpp واستيراد Jira Cloud:** يحتاجان خادم التحويل (MPXJ) وشبكة Jira؛ نسخة العرض تطلب XML أو Jira CSV.
- **فتح ملفات التصدير في GanttPRO وMicrosoft Project الأصليين:** لم يُجرَّب خارج نُزلي. والألوان لا تمرّ عبر MS Project XML (لا حقل لها في MSPDI).
- **`HttpApi` في المتصفح مع الخادم الحقيقي:** لم يُجرَّب (لا Docker هنا)؛ العقد مطابق لـ `docs/API.md`.
- **ترجمة `en.ts`:** الهيكل موجود كما يطلب البرومبت، والقيم فارغة.
- **بيانات المالك الحقيقية** (الإدارات، والمسمّيات، وأنواع المخالفات، والشعارات، والإجازات): **بانتظار المالك**. النظام يعمل الآن ببيانات تجريبية موسومة في `seed/demo/`.

## عوائق تحتاج قرار المالك

1. **GitHub Actions:** رمز الدخول المحفوظ لا يملك صلاحية `workflow`، فيرفض GitHub رفع ملفات `.github/workflows/`. لذلك:
   - يُنشر العرض بدفع ملفات البناء إلى فرع `gh-pages`.
   - تُحفظ ملفات CI في `infra/github-workflows/` غير مفعّلة.
   - لتفعيل الاختبار والنشر التلقائيين: أنشئ رمزًا فيه نطاق `workflow`.
2. **Docker غير مثبّت** على هذا الجهاز، فلم يُشغَّل الخادم مع قاعدة البيانات فعليًّا، ولم تُشغَّل اختبارات التكامل. كل الملفات جاهزة لأي جهازٍ فيه Docker.
3. **GitHub Pages لا يشغّل خادمًا:** المنشور هناك نسخة عرضٍ ببياناتٍ تجريبية داخل المتصفح (ADR-020).
4. **طابعة Zebra:** معيار قبول المرحلة 2 يتطلّب طباعةً فعليةً بمقاسَي CR80 و٩٠×٤٠.
