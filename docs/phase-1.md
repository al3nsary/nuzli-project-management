# المرحلة 1 — الأساس

التفاصيل في ملفّين: [phase-1-backend.md](phase-1-backend.md) للخادم وDocker، و[phase-1-frontend.md](phase-1-frontend.md) للواجهة ونسخة العرض.

## ما بُني

- **المستودع:** حزم pnpm (`apps/web`، `apps/api`، `packages/shared`، `packages/scheduling`، `packages/ui-print`).
- **Docker:** ملفات تطوير وإنتاج، وHTTPS إلزامي حتى في التطوير، ونسخ احتياطي مشفّر يوميًّا مع سكربت استعادة.
- **قاعدة البيانات:** PostgreSQL 16 مع ترحيلات Prisma وقيود SQL.
- **التخزين:** S3 لـ OCI، وMinIO في التطوير.
- **الحسابات:** الدخول، والتسجيل بانتظار الاعتماد، والمستخدمون والأدوار، وحماية آخر مدير.
- **المتابعة والإعدادات:** سجل التدقيق، وهيكل الإشعارات داخل النظام وبالبريد، وإعدادات النظام.
- **الواجهة:** عربية من اليمين لليسار بالهوية البصرية للمشروع.

## معيار القبول

> *مشرف جديد يسجّل فلا يستطيع الدخول، ثم يعتمده المدير فيدخل. المدير ينشئ مديرًا آخر. آخر مدير لا يمكن تخفيضه.*

| الجزء | أين اختُبر | النتيجة |
|---|---|---|
| تسجيل ← رفض الدخول ← اعتماد ← دخول | `apps/web` (DemoApi)، و`apps/api/test/int` | ✅ في نسخة العرض · ⏸️ اختبار التكامل مكتوب ويحتاج Docker |
| مدير ينشئ مديرًا | نفسهما | ✅ · ⏸️ |
| آخر مدير لا يُخفَّض، حتى لو حاول مديران تخفيض بعضهما في اللحظة نفسها | اختبار وحدة بمعاملة مُحاكاة + DemoApi + اختبار تكامل | ✅ · ⏸️ |
