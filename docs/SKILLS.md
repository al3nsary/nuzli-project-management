# المهارات واللغات والأدوات

هذا السجلّ يبيّن المهاراتِ التي استُدعيت لبناء النظام، واللغاتِ التي يُكتب بها، وأين تُحفظ قواعدُ كلٍّ منها. يُحدَّث كلما استُخدمت مهارةٌ أو أداةٌ جديدة.

## مهارات المشروع (داخل المستودع: `.claude/skills/`)

| المهارة | ماذا تحكم | متى تُحمَّل |
|---|---|---|
| `nuzli-design-system` | الألوان، والخطوط، وتوقيع «شريط السترة»، والتخطيط، وقواعد المكوّنات | قبل أي شاشة أو قالب كرت أو رسم بياني |
| `nuzli-arabic-rtl` | النصوص العربية، والاتجاه من اليمين لليسار، والأرقام، والهجري، ومدقّقات الهوية والجوال، وقواعد Excel | قبل أي نصّ أو تخطيط أو تنسيق تاريخ أو تصدير |
| `nuzli-stack-conventions` | اللغات، وبنية المستودع، وأعراف الكود والاختبار | قبل كتابة كود في أي حزمة |

## المهارات العامّة المستدعاة

| المهارة | السبب | التاريخ |
|---|---|---|
| `frontend-design` | بناء هويةٍ بصريةٍ خاصةٍ بالنظام بدل قالبٍ جاهز، ومنها خرجت `nuzli-design-system` | 2026-10-11 |
| `xlsx` | تصدير Excel من اليمين لليسار بلا تجميد أجزاء (§7.7) | يُستدعى في المرحلة 3 |
| `dataviz` | لوحة إحصاءات المخالفات (§7.5) | يُستدعى في المرحلة 3 |
| `webapp-testing` | اختبار الواجهة بـ Playwright ولقطات الشاشة | يُستدعى عند إغلاق كل مرحلة |
| `pdf` | تصدير كروت العمل ولوحة المخالفات PDF | المرحلتان 2 و3 |

## الوكلاء (`.claude/agents/`)

| الوكيل | الاختصاص |
|---|---|
| `architect` | الخطط ومخطط البيانات والقرارات المعمارية |
| `backend-nest` | الخادم (NestJS + Prisma + PostgreSQL + التخزين) |
| `frontend-rtl` | الواجهة العربية (React + Mantine) ونسخة العرض |
| `scheduling-engine` | محرّك جدولة Gantt الخالص |
| `offline-pwa` | العمل دون اتصال للمخالفات |

| `qa-tester` | الاختبارات بأنواعها ومعايير قبول المراحل |
| `docs-keeper` | تحديث البرومبت الحيّ وسجلّ الحالة والقرارات |

## اللغات

TypeScript (كل التطبيقات والحزم) · SQL لـ PostgreSQL (الترحيلات والفهارس الجزئية) · CSS · YAML (Docker و CI) · Nginx · Shell (النسخ الاحتياطي) · Markdown + Mermaid (التوثيق).
