## Decisions (answers to four questions)
1. Nozoly blue: **أزرق نيلي** (indigo).
2. Duration: **days and hours** (recommended option).
3. Import: «جميع انواع التصدير ما عدا انشاء مشروع بالذكاء الاصطناعي مع امكانية رفع ملف من مايكروسفت بروجيكت مانجر ليصبح مشروعا جاهزا» → Excel, CSV, MS Project (.mpp/.xml), Jira; all exports; no AI.
4. Violation photos: «صورة الشخص وصورة المخالفة الزامية وصورة البطاقة كذلك. سنقوم بقراءة الصورة اليا لاخذ بيانات البطاقة منها.. وتسجيلها لاحقا» → person + evidence + ID card all required; OCR the card; register/assign later.
