# المرحلة 2 — الفرق والكروت

التفاصيل في: [phase-2-backend.md](phase-2-backend.md) · [phase-2-frontend.md](phase-2-frontend.md) · [printing.md](printing.md).

## ما بُني

- **الفرق:**
  - ينشئها المدير، أو المشرف لنفسه، فتبقى بانتظار الاعتماد إن كان الإعداد مفعّلًا.
  - لكل فريقٍ لونٌ فريد، ومنتقي الألوان لا يعرض المحجوز إطلاقًا.
  - اعتماد الفريق ورفضه وأرشفته، وتغيير المشرف مع حفظ التاريخ.
- **الأعضاء:**
  - إضافتهم يدويًّا أو باللصق أو من ملف Excel، مع معاينة الأخطاء قبل الحفظ.
  - البحث بالاسم أو بآخر ٤ أرقام من الهوية.
  - سجلّ عضويةٍ لكل عضو.
- **تشكيل الفرق:** السحب والإفلات بين الأعمدة، مع النقل الجماعي والنقل بلوحة المفاتيح، ونافذة تأكيد، والتراجع عند الخطأ.
- **البيانات المرجعية:** الإدارات، والمسمّيات الوظيفية، ولوحة الألوان.
- **كروت العمل:**
  - ثلاثة قوالب، وستة مقاسات مع مقاسات مخصّصة، وشعارات.
  - كل حقلٍ قابلٌ للتعديل قبل الطباعة، مع خيار «حفظ في سجل العضو».
  - طباعة من المتصفح بمقاس الصفحة الدقيق، وسجلّ الطباعات، وصفحة طباعة تجريبية للمعايرة.

## المتبقّي

- تجربة الطباعة على طابعة Zebra حقيقية.
- خدمة PDF على الخادم (ADR-024): النقطة موجودة وتردّ برسالةٍ واضحة حتى تُشغَّل الخدمة.
