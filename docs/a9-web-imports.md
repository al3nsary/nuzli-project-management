# A9 — الواجهة: الاستيراد والتصدير والساعات

> 2026-10-19. القرارات: ADR-121 إلى ADR-123 (وتعتمد على ADR-109 إلى ADR-112 في الخادم، وADR-117 إلى ADR-120 للمراجعة الأمنية). العقد: `docs/API.md` ← «A9 — imports, exports, hours» و«A9 security review — behaviour changes». دليل المدير: `docs/imports.md`.

## ما بُني

| الموضع | المحتوى |
|---|---|
| نموذج «إنشاء مشروع جديد» | يرسل `durationUnit` و`workingDays` و`workingHours` مباشرة؛ الخادم (والعرض) يعيد استعمال التقويم الأساس إن تطابق وإلا ينشئ «تقويم {الاسم}» بعطله. تحت «أو» زرّا «استيراد Excel، CSV، MPP» و«استيراد من Jira» يفتحان المعالج (لا «قريبًا» بعد الآن). لا ذكاء اصطناعي |
| معالج الاستيراد `/projects/import` | للمدير فقط. ١) المصدر: Excel، CSV، MS Project XML، MS Project ‎.mpp، Jira (CSV)، Jira Cloud، مع «جرّب بملف نموذجي». ٢) الملف: سحب وإفلات أو اختيار، فحص الامتداد و٢٠ ميغابايت قبل الرفع، اختيار ورقة Excel، ترتيب التاريخ (يوم/شهر أو شهر/يوم)، فرض وحدة المدة، اسم المشروع؛ أو نموذج Jira Cloud (الرابط، البريد، رمز API بحقل كلمة مرور لا يُحفظ، تحذير صريح، مفتاح المشروع أو JQL) بتحقق فوري بالعربية. ٣) المعاينة: الاسم والبداية قابلان للتعديل (تغيير البداية يُزيح المهام بأيام العمل)، الوحدة، التقويم بأيام عمله وساعاته وعطله، الأعداد، التنبيهات بأسمائها العربية ونص `message_ar`، مخطط جانت للعرض فقط (الهيكل والروابط وساعات العمل واستراحة الغداء)، و«تعيين المسؤولين»: كل اسم → مشرف نشط (المطابق تمامًا مقترح) أو «بلا مسؤول». ٤) الإنشاء ثم فتح المشروع. الخطوات في الرابط (`?source=&step=`) فيعمل زر الرجوع؛ إعادة التحميل على المعاينة تعيد إلى خطوة الملف. على الهاتف سطر «الخطوة ٢ من ٤» بدل المؤشّر |
| الأخطاء | رسائل الخادم العربية كما هي، مع صياغة أوضح لفشل بنية الملف، والحجم، وحدود Excel (`xlsx-limits`/`xlsx-timeout`)، ومهلة Jira؛ ٤١٠ «انتهت صلاحية المعاينة» مع «أعد رفع الملف» وتنبيه أنّ المعاينة السادسة تزيح الأقدم؛ ٤١٣ كثرة المهام؛ ٥٠١/٥٠٢ ‎.mpp بعنوان «يتطلّب خادم التحويل — احفظ الملف بصيغة XML من MS Project ثم ارفعه» وخطوات الحفظ وزرّ «استيراد ملف XML بدلًا منه» |
| التصدير | قائمة «تصدير» في صفحة المشروع: PNG وPDF كما كانا، ثم «بيانات المهام»: Excel (من اليمين، بلا تجميد، مع التكلفتين والموعد النهائي والوسوم والحقول المخصّصة، وبالساعات في مشاريع الساعات)، CSV (UTF-8 مع BOM وتعطيل الصيغ)، MS Project XML (يعيد المستورد قراءته كما هو) |
| تحويل الوحدة | في إعدادات المشروع: الوحدة الحالية وزرّ «تحويل إلى ساعات / أيام» مع تأكيد يشرح ما يبقى وتنبيه المعالم، عبر `POST /projects/:id/convert` |
| سجل التدقيق | `project.converted` و`project.import_previewed` و`project.imported`، وشارة بصيغة التصدير/الاستيراد بجانب الإجراء، والكيان «استيراد» |
| الملفات النموذجية `apps/web/public/samples/` | بيانات تجريبية موسومة: CSV عربي (صيانة حديقة: WBS، أيام، تأخير وتقديم في الروابط)، Excel (ورقة «تعليمات» ثم «الخطة» بمستويات بالإزاحة وتكاليف ونسبة إنجاز؛ يولّدها `scripts/make-import-samples.mjs`)، MS Project XML بالساعات مع استراحة الغداء ٨–١٢ و١٣–١٧ وعطلة وموارد، وJira CSV بـEpic ومهمة فرعية وروابط blocks. تُنزّل أو تُجرَّب مباشرة، وتأخذ اسمًا عربيًّا يصير اسم المشروع |

## البيانات (HttpApi وDemoApi)

- `ApiClient.imports`: `upload` (presign بنوع المحتوى القانوني للامتداد ← PUT ← confirm)، `preview`، `jira`، `commit`؛ و`projects.export(id, format)` و`projects.convert`.
- العرض يقرأ الملفات في المتصفح بمحلّلات منقولة حرفيًّا من الخادم إلى `src/features/imports/` (النموذج وExcel/CSV وMSPDI وJira وفحص البنية)، والاختبارات نفسها على ملفات الخادم نفسها (`__fixtures__`). ملف ‎.mpp يردّ ٥٠١ لأنّ المحوّل على الخادم، وJira Cloud يتحقق من المدخلات والرابط ثم يردّ ٥٠٢ `{ reason: 'demo' }` فيعرض المعالج الشرح وزرّ Jira CSV.
- العرض يحفظ المعاينة ساعة في الذاكرة، خمسًا لكل مدير على الأكثر (السادسة تزيح الأقدم)، ويعتمدها كالخادم: حجز المعاينة أولًا، التقويم يُعاد أو يُنشأ، المشروع «تخطيط» بجدولة تلقائية، المهام عبر مسار الكتابة الواحد، المسؤولون مشرفون نشطون فقط، إعادة الأساس عند تغيير البداية، `project.imported`، وحذف الملف المرفوع.
- روابط مشاريع الساعات في العرض تحفظ التأخير بالدقائق (`lagMinutes`) وتُرسل `lagHours`، وإنشاء الرابط يقبل `lagHours`.

## المراجعة الأمنية (9a82224) في الواجهة والعرض

- تعديل المشرف لمهمته يعيد `affected: []` و`previous` لمهمته وحدها (واجهة «مهامي» لا تعتمد على `affected`)؛ مركز التواصل يعيد `path: []` للمشرف.
- تسجيل عضو من مخالفة للمدير فقط، ومع فريق لا تتجاوز المخالفة `VIOLATION_REGISTER_MAX_AGE_DAYS` (إعداد جديد في صفحة الإعدادات بالعربية) وإلا ٤٠٩ `VIOLATION_TOO_OLD_TO_REGISTER` برسالة تذكر المدة.
- تواريخ سجل الوقت بين سنة مضت وأسبوع قادم (والحقول مقيّدة بذلك)، وقيد المشرف يصبح ٤٠٤ إذا أُعيد إسناد المهمة أو أُرشفت؛ ٢٠٠ إعداد عرض لكل مستخدم (٤٠٩ `VIEW_PREF_LIMIT`)؛ حدود ٢٠٠ عمود و٥٬٠١٦ صفًّا في Excel وCSV.
- تسميات `violation.ocr_retried` و`violation.person_photo_viewed`، وأسباب فشل القراءة `IMAGE_TOO_LARGE` و`NOT_AN_IMAGE`.

## التحقق

- `tsc` نظيف، و`vitest` ٣٦٤ اختبارًا في ٣٣ ملفًّا (كانت ٣٢٠)، و`check-i18n` ٢٨٧٤ مفتاحًا، والبناءان العادي والتجريبي.
- اختبارات جديدة: `features/imports/imports.test.ts` (٢٤: اختبارات الخادم على ملفاته، ورحلة MSPDI ذهابًا وإيابًا، وتصدير xlsx من اليمين بلا تجميد وCSV بـBOM وحماية الصيغ، والملفات النموذجية، ومعاينة جانت)، `DemoApi.imports.test.ts` (٨: المعاينة والاعتماد و٤١٠ والربط بالمشرفين وإعادة الأساس وExcel وJira و‎.mpp وأخطاء الصيغة، وتصدير XML يعاد استيراده كما هو، وأيام العمل وساعاته من النموذج، والتحويل)، `importWizard.render.test.tsx` (٥: المعالج من الرفع إلى فتح المشروع، و‎.mpp وJira في العرض، وإعادة التحميل، ورسائل التحقق من Jira)، `DemoApi.securityA9.test.ts` (٦)، واختبار تسجيل العضو في `DemoApi.a9teams.test.ts`.
- Chrome بلا واجهة على نسخة العرض، 1440×900 و360×740: استيراد الملفات النموذجية الأربعة كاملًا (معاينة ← ربط ← إنشاء ← فتح المشروع) والتحقق من قاعدة البيانات: الهيكل والروابط وأنواعها وتأخيرها، والمسؤولون المربوطون، ومشروع XML بالساعات بتقويم ٨–١٢ و١٣–١٧ وعطلته، وظهور استراحة الغداء والعطلة مظلّلتين في تكبير «ساعة». تصدير MS Project XML ثم استيراده: المهام متطابقة تمامًا؛ CSV يبدأ بـBOM؛ ثلاثة تصديرات في سجل التدقيق بصيغها. مشروع ساعات من النموذج بأيام الأحد–الخميس والسبت وساعات ٩–١٣ و١٣–١٥: أُنشئ «تقويم ورشة الساعات (اختبار)» بعطلة الجمعة وحدها وعطل التقويم الأساس، ثم التحويل إلى أيام من الإعدادات مع تنبيه المعالم. لا تمرير أفقي على الهاتف.
- إصلاحات بعد المعاينة: نطاق المعاينة كان يعرض منتصف الليل في مشاريع الساعات (صار أول دقيقة عمل وآخرها)، الامتداد يظهر «(csv.)» في النص العربي (عُزل باتجاه LTR)، أرقام مختلطة في حدّ الملف، المؤشّر على الهاتف، واسم «مشروع مستورد» الافتراضي صار اسم الملف.

## ما بقي

- لم يُختبر المسار الحقيقي على الخادم (HttpApi) في المتصفح هنا؛ العقد مطابق لـ`docs/API.md` والاختبارات على العرض.
- العرض لا يشغّل حارس ZIP والعامل المنفصل اللذين في الخادم (الملف يضرّ تبويب المدير وحده)، ولا يرفض صور البطاقات فوق ٢٥ ميغابكسل في قراءته المحلية (التسميات جاهزة لرموز الخادم).
- المعاينة في العرض لا تبقى بعد إعادة تحميل الصفحة.
- `en.ts` فارغة للمفاتيح الجديدة كما في المراحل السابقة.
