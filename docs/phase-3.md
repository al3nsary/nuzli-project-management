# المرحلة 3 — المخالفات (تعمل دون اتصال)

التفاصيل في: [phase-3-backend.md](phase-3-backend.md) · [phase-3-frontend.md](phase-3-frontend.md) · [offline.md](offline.md).

## ما بُني

- **تطبيقٌ قابلٌ للتثبيت (PWA)** يعمل دون اتصال. يحفظ الواجهة والخطوط والأيقونات فقط، ولا يخزّن بيانات الخادم.
- **قائمة أعضاء مختصرة على الجهاز:** الاسم، ورقم الهوية مقنّعًا، والفريق ولونه.
- **صفحة «تسجيل مخالفة» للجوال:**
  - اختيار العضو، وصورة الهوية، وصور المخالفة.
  - النوع، والوصف، والملاحظات.
  - الوقت والموقع ودقّته بالمتر يُلتقطان تلقائيًّا. يُمنع الإرسال إن رُفض إذن الموقع، مع شرح طريقة تفعيله.
  - الصور تُصغَّر وتُزال منها بيانات EXIF.
- **صندوق إرسال ومزامنة:**
  - لا يكرّر المخالفة عند إعادة المحاولة.
  - يستأنف من حيث توقّف، ويعيد المحاولة بفواصل تتزايد.
  - شارة بعدد المخالفات التي تنتظر المزامنة.
  - تسجيل الخروج يمسح بيانات الجهاز بعد تحذير.
- **للمدير:**
  - قائمة المخالفات بالمرشّحات والخريطة.
  - التفاصيل: الصور، ودبّوس على الخريطة مع دائرة الدقّة، وتنبيه خلل ساعة الجهاز.
  - تغيير الحالة.
  - تصدير Excel من اليمين لليسار بلا تجميد.
- **لوحة الإحصاءات:**
  - المؤشرات الرئيسية، وترتيب الفرق بألوانها، والأعضاء المتكرّرون.
  - المراقبون، والأنواع والخطورة.
  - الاتجاه الزمني، والخريطة الحرارية حسب اليوم والساعة، وخريطة بالتجميع.
- **للمشرف:** يرى مخالفات فريقه ويعترض عليها، فقط إن سمح المدير بذلك.

## معيار القبول

> *مشرف مراقبة في وضع الطيران يسجّل ٣ مخالفات بالصور ثم يعود الاتصال؛ فتُرسل الثلاث مرّةً واحدة بموقعها الصحيح ولقطة الفريق وصورها.*

| أين | النتيجة |
|---|---|
| اختبار وحدة على نسخة العرض (٣ مخالفات ← اتصال ← ٣ على الخادم بلا تكرار) | ✅ |
| Chrome بلا واجهة: قطع الشبكة ← تسجيل ← إعادة تحميل ← عودة الاتصال | ✅ مخالفة واحدة بثلاث صور، وحُذفت الصور من الجهاز بعد الإرسال |
| اختبار تكامل على الخادم الحقيقي (Testcontainers) | ⏸️ ينتظر Docker |
| Playwright `e2e/offline-violation.spec.ts` | ⏸️ مكتوب، وPlaywright غير مثبّت |
| جوّالات حقيقية (iOS Safari وAndroid Chrome) عبر HTTPS | ⏳ يحتاج تجربة المالك |

## المتبقّي

- تجربة ميدانية على جوّالات حقيقية.
- خدمة PDF للوحة الإحصاءات (تُستبدل حاليًّا بطباعة المتصفح).
- لا يمكن مسح الملاحظات بالتعديل، لأنّ النص الفارغ يُعامَل في المخطّط المشترك على أنه «بلا تغيير».
