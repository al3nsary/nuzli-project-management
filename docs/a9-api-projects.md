# A9 — الخادم: المشاريع على طريقة GanttPRO

> 2026-10-19. القرارات: ADR-092 إلى ADR-097. المسارات بالتفصيل: `docs/API.md` ← «A9 — projects».

## ما بُني

| البند | الخلاصة |
|---|---|
| نطاق المشرف | لا يرى أي مشروع (403 على كل مسارات المشاريع). يرى المهام المسندة إليه فقط: المهمة، ومحادثتها (قراءة وردّ)، ومرفقاتها (قراءة وإضافة)، وقائمة تحققها (إنجاز البنود فقط)، وسجل وقته، ومركز التواصل. أي مهمة أخرى 404. جدول `project_access` باقٍ ولا يمنح شيئًا |
| الميزانية | `projects.budget` و`currency` (افتراضيًّا SAR)، و`planned_cost` و`actual_cost` لكل مهمة؛ المجموعة = مجموع أبنائها (يُحفظ ويُرقَّم كالتواريخ)، والمشروع: المخطط والفعلي والفرق ونسبة الاستهلاك. تقرير `GET /projects/:id/budget` حسب المجموعة والمسند إليه والوسم، والمهام المتجاوزة. التكلفة الفعلية يدوية، والوقت المسجّل يُعرض بالدقائق إلى جانبها |
| الوسوم والحقول المخصّصة | وسوم ملوّنة لكل مشروع تُسند عبر مسار الكتابة ذي النسخ؛ حقول نص ورقم وقائمة وتاريخ ومربع اختيار، والقيمة تُفحص حسب النوع |
| الموعد النهائي واللون وقائمة التحقق | `deadline` مع علامة `deadlinePassed` وإشعار `TASK_DEADLINE_PASSED` مرة واحدة؛ `bar_color`؛ بنود بترتيب وإنجاز ومن أنجز ومتى |
| التكرار والتعديل الجماعي | تكرار المهمة مع فروعها بعد الأصل مباشرة واسمها + « (نسخة)» والاعتماديات الداخلية معاد ربطها؛ تعديل جماعي وأرشفة جماعية واسترجاع، في معاملة واحدة مع فحص كل النسخ |
| التراجع | كل كتابة تعيد `previous` (القيم السابقة للحقول التي تغيّرت فقط)، وعكس العملية يُرسل إلى مسار الدفعة نفسه |
| إعدادات العرض | `GET/PUT/DELETE /me/view-prefs` لكل مستخدم (عامة أو لمشروع)، حتى ٣٢ كيلوبايت |
| القوالب والمحافظ | حفظ المشروع قالبًا وإنشاء مشروع من قالب بتواريخ معاد حسابها على البداية الجديدة؛ محافظ بملخص لكل مشروع ومجاميع |
| سجل الوقت | قيود بالدقائق: المشرف على مهامه وقيوده فقط، والمدير على الكل؛ `GET /me/time-entries` |
| عبء العمل والتقارير | `GET /workload` (٨ ساعات لكل يوم عمل من كل مهمة مسندة، مقابل المسجّل)، و`/projects/:id/people` و`/dashboard` و`/calendar`، و`GET /reports/projects` |
| مركز التواصل | `GET /hub` بتبويبات الكل والجديد والإشارات والمسندة والتي أنشأتها، وعدد غير المقروء ومسار الأب وآخر تعليق؛ `POST /tasks/:id/comments/read`؛ الاقتباس بـ `replyToId`؛ إشعار `TASK_COMMENTED` للمسند إليه ومن علّق قبلًا عدا الكاتب |
| متصفح المرفقات | `GET /attachments` بالتصفية حسب المشروع والنوع والرافع والتاريخ والبحث |

القاعدة: الهجرة `20261019000000_a9_projects` (جزء من `prisma migrate diff` وجزء SQL للقيود والفهارس الجزئية).

## تسميات عربية تحتاجها الواجهة

إجراءات التدقيق: `task.duplicated` · `task.restored` · `task.custom_value_set` · `task.checklist_reordered` · `label.created|updated|deleted` · `custom_field.created|updated|deleted` · `checklist_item.created|updated|deleted` · `project.saved_as_template` · `portfolio.created|updated|deleted` · `time_entry.created|updated|deleted`.

أنواع الإشعار: `TASK_COMMENTED` و`TASK_DEADLINE_PASSED`.

## الاختبارات
