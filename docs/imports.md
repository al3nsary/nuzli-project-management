# استيراد المشاريع وتصديرها

طلب المالك (A9، القرار الثالث): «جميع انواع التصدير ما عدا انشاء مشروع بالذكاء الاصطناعي مع امكانية رفع ملف من مايكروسفت بروجيكت مانجر ليصبح مشروعا جاهزا». هذا الملف دليل مدير النظام، والتفاصيل التقنية في `docs/API.md` (قسم «A9 — imports, exports, hours») وفي ADR-109 إلى ADR-112.

## الصيغ المدعومة

| الصيغة | الامتداد | كيف تُقرأ |
|---|---|---|
| Excel | ‎.xlsx | أوّل ورقة فيها عمود «اسم المهمة» (أو الورقة التي تختارها) |
| GanttPRO | ‎.xlsx | ملف «Export → Excel» من GanttPRO (يُعرف تلقائيًّا حتى لو اخترت «Excel»؛ انظر قسم GanttPRO) |
| CSV | ‎.csv | UTF-8 (مع BOM أو دونه) أو UTF-16 من Excel، والفاصل يُكتشف تلقائيًّا (فاصلة، فاصلة منقوطة، Tab) |
| MS Project XML | ‎.xml | صيغة MSPDI التي يحفظها MS Project بأمر «حفظ باسم ← XML» |
| MS Project | ‎.mpp | تُحوَّل على الخادم إلى XML بخدمة `converter` (مكتبة MPXJ) ثم تُقرأ كالسابقة |
| Jira (ملف) | ‎.csv | تصدير Jira «Export → CSV (all fields)» |
| Jira (مباشر) | — | من Jira Cloud برابط الموقع والبريد ورمز API |

**لا إنشاء مشاريع بالذكاء الاصطناعي.**

## خطوات الاستيراد

1. «إنشاء مشروع جديد» ← «استيراد» ← اختر الملف. الحدّ الأعلى **٢٠ ميغابايت** و**٥٬٠٠٠ مهمة**.
2. تظهر **معاينة**: اسم المشروع وتاريخ بدايته ووحدة المدة (أيام أو ساعات) والتقويم، والمهام بترقيمها وتواريخها بعد أن يجدولها المحرّك، والروابط، و**تنبيهات** بما لم يُفهم (صفّ بلا اسم، تاريخ غير مفهوم، سابقة غير موجودة…).
3. **اربط الأسماء بالمشرفين**: لكل اسم مسؤول في الملف اختر مشرفًا نشطًا أو اتركه بلا إسناد. إن طابق الاسم اسمَ مشرف واحد (دون اعتبار لحالة الأحرف والمسافات) أو الجزءَ الأول من بريده (`sami` من `sami@…`) يُقترح تلقائيًّا. (المهام تُسند إلى المشرفين فقط.)

**الصيغة تُعرف من المحتوى (A10):** ملف GanttPRO يُقرأ بقارئ GanttPRO ولو اخترت «Excel»، وملف MS Project XML يُقرأ كـXML ولو اخترت غيره؛ تظهر في المعاينة الصيغة المكتشفة وتنبيه بذلك. أمّا ملفّ نصّي مُرسل على أنه Excel فيُرفض كما كان.
4. عدّل الاسم أو تاريخ البداية إن شئت (تغيير البداية يُزيح كل المهام بعدد أيام العمل نفسه)، ثم «اعتماد».
5. يُنشأ المشروع وتقويمه ومهامه وروابطه في عملية واحدة: إمّا كلّها أو لا شيء. يُحذف الملف المرفوع بعد الاعتماد.

المعاينة صالحة **ساعة واحدة**؛ بعدها يُحذف الملف ويلزم رفعه من جديد. الاعتماد مرّة واحدة فقط.

## أسماء الأعمدة في Excel وCSV

صفّ العناوين هو أوّل صفّ (ضمن أوّل ١٥ صفًّا) فيه عمود اسم المهمة. لا يهمّ ترتيب الأعمدة، ولا الهمزات والتشكيل وحروف الكبيرة والصغيرة. العمود غير المعروف يُتجاهل.

| الحقل | أسماء مقبولة (أمثلة) |
|---|---|
| اسم المهمة **(إلزامي)** | اسم المهمة، المهمة، اسم النشاط، البند، العنوان · Task name, Task, Name, Title, Activity |
| المعرّف (للسابقات) | المعرف، الرقم، رقم المهمة، م · ID, Task ID, Unique ID, # |
| رقم WBS | رقم WBS، الترقيم، رمز WBS · WBS, Outline number |
| المستوى | المستوى، مستوى المخطط · Outline level, Level |
| البداية | البداية، تاريخ البداية، البدء · Start, Start date |
| النهاية | النهاية، تاريخ النهاية، الانتهاء · Finish, End, End date |
| المدة | المدة، المدة (أيام)، **المدة (ساعات)** · Duration, Duration (hours), Days, Hours |
| المسؤول | المسؤول، المسند إليه، المكلف، المنفذ، الموارد · Assigned, Assignee, Resource names, Owner |
| الحالة | الحالة · Status |
| التقدم | التقدم، نسبة الإنجاز، الإنجاز · Progress, % Complete |
| السابقة | السابقة، المهام السابقة، الاعتماديات · Predecessors, Depends on |
| التكلفة | التكلفة، التكلفة المخططة، الميزانية · Cost, Planned cost, Budget |
| التكلفة الفعلية | التكلفة الفعلية · Actual cost |
| الموعد النهائي | الموعد النهائي · Deadline, Due date |
| الملاحظات | ملاحظات، الوصف · Notes, Description |
| النوع | النوع، معلم · Type, Milestone (القيم: «معلم»/milestone، «مجموعة»/summary) |

**الهيكل (المهام الفرعية)** بأيّ من: رقم WBS (‏1، 1.2، 1.2.3)، أو عمود المستوى (1 للجذر)، أو **إزاحة** اسم المهمة في الخلية (المسافة البادئة في Excel أو مسافتان في أوّل الاسم في CSV). المهمة التي تحتها مهامّ تصبح مجموعة تُحسب تواريخها وتكلفتها من أبنائها.

**التواريخ**: خلايا تاريخ Excel، و`2026-10-11`، و`11/10/2026` (اليوم أولًا، ويمكن اختيار الشهر أولًا)، والأرقام الهندية (‏١١/١٠/٢٠٢٦)، وأسماء الأشهر (11 أكتوبر 2026، Oct 11 2026)، ومع الوقت (14:30 أو 2:30 م).

**المدة**: `5` أو `5 أيام` أو `1 أسبوع` (= ٥ أيام) أو `4 ساعات` أو `4h` أو `30 دقيقة`. إن كان العمود «المدة (ساعات)» فالأرقام ساعات.

**السابقات**: رقم المهمة (`5`)، أو مع النوع والتأخير (`3FS+2d`، `4SS-1d`، `7FF+3h`)، وعدّة سابقات تُفصل بفاصلة منقوطة أو فاصلة (`2;5`). الرقم يشير إلى عمود المعرّف إن وُجد، وإلا إلى رقم WBS أو رقم الصفّ بين المهام.

**الحالة**: لم تبدأ، قيد التنفيذ، مكتملة، معلّقة (وما يقابلها بالإنجليزية). إن غابت تُستنتج من نسبة الإنجاز.

ملف Excel أو CSV الذي يصدّره نزلي نفسه يُستورد كما هو.

## وحدة المدة: أيام أم ساعات

يُنشأ المشروع **بالساعات** تلقائيًّا إذا كان في الملف عمود «المدة (ساعات)»، أو مدّة ليست أيامًا كاملة (مثل ٤ ساعات)، أو صيغة مدد بالساعات في MS Project. غير ذلك **بالأيام**. يمكن فرض الوحدة من خيارات الاستيراد. وبعد الإنشاء يمكن تحويل أيّ مشروع بين الأيام والساعات من إعداداته (كل مهمة تبقى على أيّام عملها نفسها).

## GanttPRO

### التصدير من GanttPRO

1. افتح المشروع في GanttPRO.
2. من القائمة أعلى المخطط: **Export ← Excel** (تصدير ← Excel). اترك الأعمدة الافتراضية كما هي.
3. احفظ الملف (‎.xlsx)، ثم استورده في نزلي واختر «GanttPRO» (أو «Excel» — يُعرف تلقائيًّا).

يُعرف ملف GanttPRO بصفّ عناوينه (الصفّ الخامس: `WBS Number` و`Task name / Title` و`Type` و`Level`…) أو بشريطه العلوي، ويُقبل بلغات واجهة GanttPRO الأخرى (العربية والروسية وغيرهما)؛ وإن كانت العناوين بلغة غير معروفة تُقرأ الأعمدة بمواضعها المعتادة.

### ماذا يُنقل من GanttPRO

| في GanttPRO | في نزلي |
|---|---|
| الصفوف ١–٤ (الشريط) | اسم المشروع من الصفّ الرابع (أو اسم الورقة) |
| السطر الأخير «This document has been created with the help of ganttpro.com» والصفوف الفارغة | تُتجاهل |
| `Color` — **لون تعبئة الخلية** في العمود A | لون شريط المهمة (`#RRGGBB`) |
| `WBS Number` | الهيكل (المرجع الأساسي)؛ `Level` يُقارن به ويظهر تنبيه إن اختلفا |
| `Task name / Title` — الاسم في الأعمدة C إلى G مدموجةً حسب المستوى | اسم المهمة (أوّل خلية غير فارغة) |
| `Type`: `project` / `tasks group` | مجموعة. إن كان في الملف صفّ واحد فقط في المستوى الأول من نوع `project` واسمه هو اسم المشروع، يصبح اسمَ المشروع ولا يُستورد كمهمة |
| `Type`: `task` / `milestone` | مهمة / معلَم |
| `Planned start date` / `Planned end date` (بتوقيت UTC) | البداية والنهاية **بتوقيت الرياض** (‏07:00Z ← ‏10:00) |
| `Duration (hours)` | المدة بالساعات ← **المشروع يُنشأ بالساعات** (أقلّ مدة ١٥ دقيقة، ويظهر تنبيه إن قُرّبت مدة أقصر) |
| `Deadline` | الموعد النهائي (اليوم كما في GanttPRO) |
| `Progress (%)` | نسبة الإنجاز |
| `Status`: Open / In progress / Done / Closed / On hold | لم تبدأ / قيد التنفيذ / مكتملة / مكتملة / معلّقة (والقيمة غير المعروفة ← لم تبدأ مع تنبيه) |
| `Priority`: Lowest / Low / Medium / High / Highest | منخفضة / منخفضة / متوسطة / عالية / عاجلة |
| `Task description` | الوصف (الأسطر والروابط كما هي) |
| `Predecessor` — أرقام WBS (`2.1.3`، `2.1.3FS+2h`، `1.2; 3.1`) | روابط بأنواعها مع التأخير |
| `Assigned to` | اسم المسؤول (يُربط بمشرف في المعاينة؛ إن كانوا أكثر من واحد يُؤخذ الأول مع تنبيه) |
| `Budget` / `Actual cost` | التكلفة المخططة / الفعلية |
| `Estimated hours` و`Time log (minutes)` | **لا تُستورد**؛ مجموعها يظهر في المعاينة وفي تنبيه |
| `Created` و`Creator` و`Project` | لا تُستورد (`Project` مسار الأسلاف فقط) |

**التقويم:** ملف GanttPRO لا يحمل تقويمه، فيُستنتج من أوقات المهام: بداية اليوم = أبكر وقت بداية متكرّر، ونهايته = أبعد وقت نهاية متكرّر، والاستراحة حيث تفسّر مدد المهام، والعطلة = أيام الأسبوع التي لا تبدأ فيها مهمة ولا تنتهي. يظهر تنبيه «CALENDAR_DEFAULTED» بالتقويم المستنتج وعدد المهام التي يطابقها — راجعه بعد الاستيراد. إن لم يكفِ الملف للاستنتاج يُستعمل الافتراضي (الجمعة والسبت، ‏09–13 و14–18).

**الروابط:** محرّك نزلي يحترم «انتهاء ← بداية»؛ مهمة كانت في GanttPRO تبدأ قبل انتهاء سابقتها تُزاح إلى ما بعدها.

## ملفات MS Project

يُقرأ ما يحفظه MS Project من ٢٠١٠ إلى ٢٠٢١ (و Project لـ Microsoft 365): مساحة الأسماء `http://schemas.microsoft.com/project`، والأسماء العربية، ومستويات المخطط، والمهام الملخّصة، والمعالم، والموارد والإسنادات (موارد العمل فقط؛ المواد والتكاليف تُتجاهل)، وتقويم المشروع المحدَّد في `CalendarUID` مع عطله. المهام **المعطّلة** (Inactive) لا تُستورد ويظهر تنبيه بعددها. وما لا يحتاجه نزلي (خطوط الأساس، الحقول المخصّصة، التوزيع الزمني) يُتجاهل.

### الأفضل: احفظ الملف بصيغة XML

1. افتح المشروع في Microsoft Project.
2. **ملف ← حفظ باسم** (File ← Save As).
3. في «نوع الملف» اختر **XML Format (*.xml)**.
4. احفظ، ثم استورد الملف من نزلي واختر «MS Project XML».

يُقرأ من الملف: المهام وهيكلها والمهام الملخّصة والمعالم، والبداية والنهاية والمدة، ونسبة الإنجاز، والتكلفة والتكلفة الفعلية، والموعد النهائي، والملاحظات، والروابط بأنواعها الأربعة مع التأخير، والموارد المسندة (اسم واحد لكل مهمة: صاحب أكبر نسبة)، وتقويم المشروع (أيام العمل وساعاتها والعطل).

ملاحظات:
- روابط «بداية ← بداية» و«انتهاء ← انتهاء» و«بداية ← انتهاء» تُحفظ كما هي، لكن محرّك الجدولة في نزلي يحرّك المواعيد بروابط «انتهاء ← بداية» فقط (يظهر تنبيه بذلك).
- التأخير بالنسبة المئوية لا يُدعم ويُعتبر صفرًا.
- الروابط إلى مشاريع أخرى تُترك.

### ملف ‎.mpp مباشرة

يعمل حين يكون مدير الخادم قد شغّل خدمة التحويل (`converter`) وضبط `CONVERTER_URL` و`CONVERTER_TOKEN`. إن لم تكن مفعّلة تظهر رسالة: «تحويل ملفات ‎.mpp غير مفعّل على هذا الخادم…» — احفظ الملف بصيغة XML كما في الخطوات السابقة.

## Jira

### من ملف CSV

1. في Jira افتح البحث عن المهام (Filters ← Advanced issue search) واكتب الاستعلام، مثل `project = OPS`.
2. **Export ← Export CSV (all fields)**.
3. استورد الملف في نزلي واختر «Jira CSV».

### مباشرة من Jira Cloud

1. أنشئ رمز API من حسابك في Atlassian: ‏`https://id.atlassian.com/manage-profile/security/api-tokens` ← «Create API token».
2. في نزلي: «استيراد من Jira» ← رابط الموقع (مثل `https://acme.atlassian.net`) والبريد والرمز، ومفتاح المشروع (مثل `OPS`) أو استعلام JQL.
3. يُستعمل الرمز لهذا الطلب فقط: **لا يُحفظ ولا يُسجَّل**. الحدّ الأعلى ٢٬٠٠٠ مهمة؛ ضيّق الاستعلام للباقي.

يُقبل `https://<اسم>.atlassian.net` فقط، وأيّ خادم Jira آخر يضيفه مدير الخادم في `JIRA_ALLOWED_HOSTS`.

### ماذا يُنقل من Jira

| في Jira | في نزلي |
|---|---|
| Epic | مجموعة |
| Story / Task / Bug | مهمة تحت الـEpic إن كان لها Epic Link أو Parent |
| Sub-task | مهمة فرعية تحت أصلها |
| Status | الحالة (Done ← مكتملة، In Progress ← قيد التنفيذ، Blocked ← معلّقة…) |
| Assignee | اسم المسؤول (يُربط بمشرف في المعاينة) |
| Start date (حقل مخصّص) أو Created | البداية |
| Due date | النهاية والموعد النهائي |
| Original Estimate | المدة |
| blocks / is blocked by | رابط «انتهاء ← بداية» |

مشاريع Jira تُنشأ بالأيام ما لم تختر الساعات.

## التصدير

من صفحة المشروع ← «تصدير»:

| الصيغة | المحتوى |
|---|---|
| Excel ‏(.xlsx) | ورقة «المهام» وورقة «المشروع»، من اليمين إلى اليسار، **دون تجميد أجزاء**؛ الأعمدة: رقم WBS، المهمة (بإزاحة حسب المستوى)، النوع، البداية، النهاية، المدة، نسبة الإنجاز، الحالة، الأولوية، المسند إليه، الفريق، الوصف، التكلفة المخططة، التكلفة الفعلية، الموعد النهائي، الوسوم، ثم عمود لكل حقل مخصّص |
| CSV | الأعمدة نفسها بترميز UTF-8 مع BOM (فتظهر العربية صحيحة في Excel) |
| MS Project XML | يفتحه MS Project مباشرة: التقويم وساعاته وعطله، والمهام الملخّصة، والمدد، والروابط مع التأخير، والمسؤولون كموارد |
| GanttPRO ‏(.xlsx) | **بتخطيط ملف GanttPRO نفسه**: الشريط في الصفوف ١–٤، والعناوين الإنجليزية في الصفّ الخامس، ولون الشريط تعبئةً في العمود A، ورقم WBS، والاسم مدموجًا من عمود مستواه إلى G، والتواريخ بتوقيت UTC، والمدة بالساعات، والحالة والأولوية بكلمات GanttPRO، والسابقات بأرقام WBS (مع النوع والتأخير إن لم يكن «انتهاء ← بداية» بلا تأخير)، والتكاليف، والنوع (`project` لمجموعات المستوى الأول، `tasks group` لما تحتها)، ومسار المشروع، والمستوى، وفي آخره «Exported from Nozoly». تُضاف ورقة مخفية «Nozoly calendar» بالتقويم ووحدة المدة فيُعاد استيراد الملف في نزلي **كما هو تمامًا**، ويستورده GanttPRO من «Import → Excel». الورقة من اليمين إلى اليسار ودون تجميد أجزاء كسائر ملفات نزلي |
| PDF / PNG | صورة مخطط جانت تُنشأ في المتصفح |

كل تصدير يُسجَّل في سجلّ التدقيق مع صيغته.

## حدود ومسائل أمان

- الاستيراد لمدير النظام فقط. الملف في حاوية خاصة، ولا يقرؤه إلا من رفعه، ويُحذف بعد الاعتماد أو بعد انتهاء المعاينة.
- يُفحص محتوى الملف لا امتداده فقط: Excel حقيقي، وXML بلا DOCTYPE (حماية من XXE)، و‎.mpp بتوقيع ملفات Office، وCSV نصّ.
- في تصدير CSV تُعطَّل الخلايا التي تبدأ بـ`=` أو `+` أو `-` أو `@` (حماية من حقن الصيغ).
- خدمة التحويل داخلية لا تُنشر للإنترنت وتطلب رمزًا سرّيًّا مع كل طلب، وتقطع أيّ تحويل يتجاوز ٥٠ ثانية.
- **ملفات Excel المفخّخة (مراجعة الأمان A9، ADR-119):** يُفحص فهرس ملف ZIP قبل قراءته: ٢٬٠٠٠ جزء على الأكثر، و١٠٠ ميغابايت بعد فكّ الضغط، و٥٠ ميغابايت للجزء الواحد، ونسبة ضغط لا تتجاوز ١٠٠ إلى ١، ويُتحقَّق من أن كل جزء يُفكّ إلى الحجم المعلن. تُقرأ الخلايا الفعلية فقط، حتى ٢٠٠ عمود و٥٬٠١٦ صفًّا غير فارغ، داخل عامل منفصل بذاكرة محدودة (٢٥٦ م.ب) ومهلة ٣٠ ثانية؛ أيّ تجاوز يرفض الملف ولا يمسّ الخادم.
- لكل مدير خمس معاينات على الأكثر؛ السادسة تحذف أقدمها.
- استيراد Jira له مهلة كلية واحدة (٦٠ ثانية) لكل الصفحات.
- خدمة التحويل على شبكة داخلية بلا اتصال بالإنترنت، وكل تحويل يجري في عملية مستقلة تُقتل عند انتهاء المهلة (ADR-120).
