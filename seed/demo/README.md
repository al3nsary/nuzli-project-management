# بيانات العرض التجريبية — `seed/demo`

> **هذه بيانات تجريبية لنسخة العرض فقط، وليست بيانات حقيقية.** تُستبدل ببيانات المالك عند توفّرها (البرومبت §0 القاعدة 2).

- الأسماء وأرقام الجوال والبريد مختلقة. البريد على النطاق المحجوز `demo.nuzli.example`.
- أرقام الهوية/الإقامة مولّدة لتجتاز خوارزمية رقم التحقق (`nationalIdCheckDigit` من `@nuzli/shared`) فقط، ولا تخصّ أحدًا.
- تقرؤها نسخة العرض على GitHub Pages (`DemoApi` في `apps/web/src/api/demo/`) عند أول تشغيل، ثم تحفظ التعديلات في IndexedDB على متصفح الزائر. زر «إعادة ضبط بيانات العرض» يعيدها إلى هذه الملفات.
- كلمة المرور المشتركة لكل الحسابات التجريبية: `NuzliDemo2026` (معرّفة في `apps/web/src/api/demo/constants.ts`).

| الملف | المحتوى |
|---|---|
| `users.json` | مديران، ٤ مشرفين (أحدهم موقوف)، ٣ مشرفي مراقبة، ٣ طلبات تسجيل معلّقة، طلب مرفوض |
| `notifications.json` | إشعارات طلبات التسجيل للمديرين، وإشعارات اعتماد |
| `audit.json` | عيّنة من سجل التدقيق |

حقول `users.json` تطابق `UserDto` في `@nuzli/shared` مع الرقم الكامل للهوية (`nationalId`) وجوال بصيغة E.164.
